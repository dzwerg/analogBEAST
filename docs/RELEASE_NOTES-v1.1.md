# analogBEAST v1.1 — Live Performance & Advanced SONG Arranger

**Custom synthesizer / hardware sequencer firmware for the M-VAVE FM-1.**

Version 1.1 focuses on live playing, smarter SONG arrangements and editing workflows. It extends v1.0's two synthesis routings (MIKROKORG and BRUTE), 128 pattern slots, 32 SONGs and 4 ALBUMs without replacing the existing SONG/backup storage layout.

## New SONG commands

| Command | Meaning |
|---|---|
| `OCTAVE` | Transpose subsequent song notes by **−3 to +3 octaves** until changed again |
| `TRANSPOSE` | Transpose subsequent song notes by **−24 to +24 semitones** until changed again |
| `REPEAT` | Play the **next pattern** a total of 1–64 times |
| `JUMP` | Set the starting step (1–64) for the next pattern |
| `ENDSTEP` | Set the ending step (1–64) for the next pattern |
| `BEGIN` | Return to the beginning at SONG `END`, even if SONG ONCE was selected |

Example arrangement:

```text
JUMP     12
ENDSTEP  13
REPEAT    5
A02      64
A03      64
END
```

This plays **steps 12–13 of A02 five times in total**, then starts A03 from its normal beginning. `BEGIN` loops a SONG, not the whole ALBUM; on a `BEGIN`-induced replay, existing live tempo/preset changes are not automatically undone by reapplying the initial commands.

## Live hardware performance

- On the PLAY page, **8 black keys** select BANK A–H and **16 white keys** select PATTERN 01–16.
- While PATTERN transport runs, a selected pattern is **queued for the next pattern boundary**, not cut in immediately.
- **PRESET** can be turned during playback without restarting the transport or replacing the current sequence.
- **ALGORITHM** adjusts tempo outside the HOME page too.
- **OCT− / OCT+** shift live sequence pitch one octave at a time; STOP clears live pitch offsets and a pending NEXT.
- Keyboard LEDs reflect playing notes (including pitch changes) rather than marking bank/pattern selections.
- SONG/ALBUM modes keep their existing end-of-song queued navigation.

## Web editor and MIDI transfer

- Piano roll: quick **TRANSPOSE −1/+1** and **OCTAVE −12/+12** actions, undo support, bounded note values, corrected TIE presentation.
- Python transfer CLI updated for SONG command IDs **13–18**.
- The 4-byte-per-row SONG model and 13,648-byte v5 payload remain unchanged. Existing v1.0 SONG rows and SysEx operations remain compatible; no automatic rewrite of v1.0 arrangements.
- SONG/ALBUM transfer supports write → readback → backup → restore, with a write lock when transport is running.

## Download and compatibility

- **`analogBEAST-v1.1.fwsc`** — the byte-identical, hardware-tested v1.1 developer firmware package, renamed for distribution.
- **`SHA256SUMS-v1.1.txt`** — SHA-256 for the published package.
- Source archives generated by GitHub.

The firmware **retains `FM-1_901`** and the **`Felucca Update`** loader identity. Do **not** use `build.sh --release 1.1` for this package: the upstream release build changes the identity and is not the tested package. The internal menu version label in the hardware-tested binary may still display `v1.0`; the functional code and release package are v1.1.

**Back up presets, patterns, SONGs, ALBUMs and device settings before updating.** The published website/WebAssembly emulator may still reflect the prior build until separately redeployed; the firmware package in this release is the authoritative v1.1 download.
