# analogBEAST v1.0 — First Public Release

**Custom synthesizer and full-song sequencer firmware for M-VAVE FM-1.**

analogBEAST brings two distinct synthesis signal paths, a characterful digital Steiner-Parker-inspired filter, 128 pattern slots and hardware SONG/ALBUM playback to the FM-1 — accompanied by a graphical Web Studio, WebAssembly emulator and browser-based USB installer.

## Synthesis — two different routings

**MIKROKORG:** virtual-analog-inspired dual-oscillator structure with oscillator sync, ring modulation, envelope/LFO modulation, filter choices and effects.

**BRUTE:** a different oscillator path with SAW/ULTRASAW, PULSE/PWM, METAL-style wavefolding, SUB/overtone components, Brute Factor internal feedback, and a **digital Steiner-Parker-inspired two-pole filter** with selectable LP/BP/HP responses and nonlinear saturation.

The two routings are implemented inside the same **GOLANA** engine. The Steiner-Parker filter is digitally inspired by the original concept; it is not a circuit-accurate clone.

## Sequencer and performance

- **128 patterns** in **8 banks** (A–H), **16 patterns per bank**.
- **Banks A–D:** up to **64 steps** per pattern.
- **Banks E–H:** up to **16 steps** per pattern.
- Note, velocity, gate, swing, timing and step flags/type editing.
- **SONG MODE:** **32 songs**, up to **64 rows/commands** each; PATTERN, TEMPO, PRESET, REST, ARP and END; once/repeat playback.
- **ALBUM MODE:** **4 albums**, up to **32 song entries** each; ordered playback of saved songs.
- **32 sound programs P01–P32**, selectable with MIDI Program Change.
- USB MIDI and song/pattern transfer tooling.

## Web applications

- **[Project homepage](https://dzwerg.github.io/analogBEAST/)** — the entry point for all browser tools.
- **[Synth Studio](https://dzwerg.github.io/analogBEAST/webapp/editor/)** — synthesis and ARP editing, P01–P32 program selector, graphical pattern/SONG/ALBUM editor, and MIDI-song import.
- **[FM-1 Web Emulator](https://dzwerg.github.io/analogBEAST/emu/)** — WebAssembly-based simulation, usable without FM-1 hardware.
- **[USB Web Installer](https://dzwerg.github.io/analogBEAST/webapp/installer/)** — requires a compatible browser (e.g., Chrome/Edge) with MIDI/SysEx access. Check device detection; back up personal data before flashing.

## Compatibility and safety

The firmware deliberately keeps the compatible FM-1 package identity **`FM-1_901`** and the **`Felucca Update`** loader identity. Back up all user programs, patterns, songs and projects before installing or updating. This is independent custom firmware, provided **without warranty**.
